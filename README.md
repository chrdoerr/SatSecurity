# Artifacts: counterspace threat awareness of satellite mission actors

Artifact repository for the paper (anonymous for review, frozen at the submission deadline). Folders 1–4 follow the list in the paper's Open Science appendix.

| Folder | Content | In the paper |
|---|---|---|
| `1_taxonomy/` | Taxonomy of the nine threat types with damage scope and persistence, attacker profile, detectability, attribution and protection options (`taxonomy.csv`, `taxonomy.md`), and Figure 1 at full size (`taxonomy.pdf`) | Figure 1, Section 4.1 |
| `2_interview_guides/` | Interview guides of both series in their original language | Appendices A and B |
| `3_rubric/` | Assessment rubric: anchors (English, Table 4), full rubric in the original German wording, coding instructions | Table 4, Section 4.3, Appendices C and D |
| `4_data/` | Expert ratings aggregated per threat type and domain; consensus coding per organization (pseudonyms); levels of both coders before consensus with a script that reproduces their agreement | Figures 2 and 3, Tables 1–3, Sections 4.3 and 6 |
| `5_source_snapshots/` | Retrieved values of continuously updated web sources cited in the paper | References |

## Not included

- Interview transcripts. The mission stakeholders consented to the publication of anonymized quotes only, and a domain expert could identify organizations from mission details even after redaction.
- Per-expert ratings; only the aggregates per threat type and domain are released.
- Organization attributes beyond those reported in the paper, to prevent re-identification.
